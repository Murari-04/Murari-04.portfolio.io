Prepare the data

FEATURED CASE STUDY / 02

Safer prompts.
More reliable AI.

LLM Guardrails · Exploring checks around a Gemini-powered generation workflow

01

Identify the risks

Consider what can go wrong when an application accepts user prompts and returns model-generated text, including irrelevant, unsafe, or unexpected inputs and outputs.

02

Check incoming prompts

Use input validation and prompt checks to decide whether a request should proceed to the model. Keep validation rules explicit and easy to test.

03

Review generated responses

Inspect the model response before showing it to the user, and handle responses that fail the application's expected checks.

04

Test and improve

Try normal, malformed, and edge-case prompts; record where checks succeed or fail. Guardrails can reduce some risks, but they cannot guarantee that every model response is safe or correct.
