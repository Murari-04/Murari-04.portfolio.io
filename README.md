## 💻 Run Locally

Follow these steps to run the portfolio on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/Murari-04/Murari-04.portfolio.io.git
```

**2. Navigate to the project directory**

```bash
cd Murari-04.portfolio.io
```

**3. Open the project**

Open `index.html` directly in your browser or use the **Live Server** extension in Visual Studio Code.

No additional dependencies or package installations are required.

## 🌍 Deployment

This portfolio can be hosted using GitHub Pages.

1. Open the repository on GitHub.
2. Navigate to **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.

Once GitHub Pages finishes deployment, your portfolio will be accessible through the published URL shown in the Pages settings.
